# Release notes

## 0.4.9 — 2026-11-01

- Build and revise complex structures in conversation, then prepare calculations from them.
- Work with point defects, charge states and SIESTA calculations.
- Inspect MD trajectories and thermodynamic results; continue supported calculations from verified checkpoints.
- Revise task parameters and computing resources without overwriting previous attempts.
- Create reports, tables and plots from recorded results.
- Fix connection recovery, model switching and continuation details shown during input review.

This release provides the macOS Apple Silicon app and documentation. The application source tree is not published. Windows end-to-end acceptance is still pending, so no new Windows installer is included. Earlier releases and their licenses remain unchanged.
