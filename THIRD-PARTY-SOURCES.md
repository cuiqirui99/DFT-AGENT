# Third-party source materials

The companion `DFT-Agent-0.5.0-Third-Party-Sources.tar.gz` contains the upstream
source materials for ASE 3.29.0, certifi 2026.10.23, orjson 3.13.0, tqdm 4.70.1
and their included dependencies. It contains no DFT Agent first-party source.

Download it beside the macOS installer at:
https://github.com/cuiqirui99/DFT-AGENT/releases/tag/v0.5.0

The same source archive accompanies the DFT Agent 0.5.0 Zenodo version, reached
through https://doi.org/10.5281/zenodo.23260916 . Select version 0.5.0.
The archive must be published together with the application on both services.

`manifest.json` records exact file hashes and upstream URLs. Python archives
were verified against PyPI's SHA-256 records.

ASE is unmodified upstream code. Extract its archive to inspect or change it;
see LGPL_REPLACEMENT.md to replace the application copy. MPL component source
and data are provided unchanged and retain MPL-2.0 rights. The source archives
carry their own original licenses, including licenses of bundled subcomponents.

These are source materials for third-party components, not a source-code offer
for proprietary DFT Agent code. The application license does not limit the
rights provided by those third-party licenses.
